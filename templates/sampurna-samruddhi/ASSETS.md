# Assets needed for HyperFrames renders

This template repo documents slots. **Copy real files into each video project** (do not invent photos).

| Asset | Suggested path in a video project | Notes |
| --- | --- | --- |
| Logo | `assets/brand/logo.png` or `public/logo.png` | From FABSELFHELP `assets/brand/logo.png` or Canva |
| Founder photo | `assets/team/founder.png` | Circular crop friendly; Ramesh Inamdar |
| Co-founder photo | `assets/team/cofounder.png` | Circular crop friendly |
| Noto Sans Devanagari | `assets/fonts/NotoSansDevanagari-*.ttf` | [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Sans+Devanagari) — required for quality Marathi |
| Display / body fonts | Google Fonts link or local woff2 | Cormorant Garamond + Source Sans 3 (or Playfair + DM Sans) |
| Ambient BGM | `assets/music/ambient.mp3` | Soft bed under VO |
| Voice reference (optional) | `assets/voice/reference.wav` | 30–60s quiet room, for later clone — not required for HyperFrames TTS |

Until photos exist in the project, compositions must use **gold ring + role label placeholders** — never generated faces.
